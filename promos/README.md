# Plugin Store promo images

Marketing images for the Black Hole listing on the Craft Plugin Store, rendered in the same theme
as the plugin's marketing page at
[justinholt.com/plugins/craft-blackhole](https://justinholt.com/plugins/craft-blackhole).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `blackhole-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome,
then downsampled so the type stays crisp).

screenshot slides can be added alongside these without redoing anything: copy the `.shot` /
`.viewport` pattern from `craft-appleseed-website/promos/slides.html`.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#E8912D`, Jersey 20 for display, Inter for body.

**Every address on these slides is in a documentation range** — RFC 5737 (`192.0.2.0/24`,
`198.51.100.0/24`, `203.0.113.0/24`) and RFC 3849 (`2001:db8::/32`), the same ranges the plugin's
integration checks use. A promo that labels a real routable address as a caught bad bot is
publishing an accusation about somebody's network. The first draft of slide 6 had `2a03:2880:f0::1`
on it, which is Facebook's.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon for the cover mark and footer lockup. Same two files as
  `web/images/plugins/blackhole.svg` on the marketing site: a `rx="22.44"` tile in the accent
  colour with a `#FEFEFE` glyph, which is what all 40 plugin icons do.
- `watermark.svg` — the glyph with the tile stripped, no fill of its own.

### The mark is a ring, and the ring has nothing in it

The obvious drawing of a black hole is an accretion disk with the event horizon filled in behind
it — a ring around a disc. Do not. A light ring with a dark centre on a bright field is an eye:
sclera, iris, pupil. It is the only thing anyone sees once they have seen it, and it holds at every
size down to 24px. Inverting the values is worse — that is an eye with lids.

**The hole in the ring is the horizon.** Nothing else needs drawing, and it happens to be what a
black hole actually photographs as.

There is a geometric trap underneath this. The disk's inner edge is an ellipse of `ry="16"`, so a
horizon circle of `r="16.5"` — the value the original glyph carried — overruns it top and bottom
and pinches the white ring thin at exactly the two points that carry the shape. Pull the circle in
far enough to clear the edge and it is inside the hole, invisible, doing nothing. Either way the
right answer is to delete it.

In the plugin repo the two files are **not** the same drawing, which is the family's split:

- `src/icon.svg` is the Plugin Store icon — the tile, byte-identical in geometry to this one and
  to `web/images/plugins/blackhole.svg`.
- `src/icon-mask.svg` is the control-panel nav icon, which Craft paints as a flat silhouette at
  about 16px. At that size the tile's 8-unit band goes spindly and the hole all but closes, so the
  ring is **redrawn heavier** — outer 46x26, hole 31x12. `craft-alarmclock` redraws its mask for
  the same reason; `craft-bird` gets away with reusing its path because its holes are large.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
